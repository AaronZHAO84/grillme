grillme：先问清楚，再开始做

一个适用于 Codex、Claude Code 与 DeepSeek Harness（DSH）的方案澄清 Skill。它一次只问一个关键问题，并先给出推荐答案与主要取舍。

安装后请重新打开对应运行时，让 Skill 目录重新扫描。

安装

Windows: .\install.ps1 -Targets all

macOS / Linux: ./install.sh all

调用

$grillme 我想做一个面向小团队的库存管理工具

工作方式

每轮先给推荐，再说明取舍，随后只提出一个问题。能从代码库、文档或测试中确认的事实，应先自行检查。

控制词

输入作用
accept接受推荐答案
change: …指定替代方案
summary查看当前决策台账
stop输出当前决策简报

结束标准

当目标、边界、非目标、成功标准、关键取舍、风险和下一步已经清晰时结束。结束访谈不等于授权实施，需要另行明确要求开始构建。
